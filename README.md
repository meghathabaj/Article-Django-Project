# Article Website Using Django

## Project Description

A dynamic multi-category article website developed using Python, Django, HTML, and CSS.

The website displays articles, news, blogs, sports, and international content in a card-based layout. Users can browse different categories and click the **Read More** button to view the complete description of the selected content on a separate page.

## Features

- Displays content with images, titles, and descriptions.
- Includes Articles, News, Blogs, Sports, and International sections.
- Provides a Read More option for individual content.
- Uses dynamic URL routing to display selected content based on its ID.
- Uses Django template inheritance for reusable page layouts.
- Provides category-based navigation.

## Technologies Used

- Python
- Django
- HTML
- CSS

## Django Concepts Implemented

- Function-Based Views
- URL Routing
- Django Templates
- Template Inheritance
- Template Variables and For Loops
- Dynamic Content Rendering
- Static Files Management

## How to Run

1. Clone the repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the development server using `python manage.py runserver`.
4. Open `http://127.0.0.1:8000/` in your browser.
